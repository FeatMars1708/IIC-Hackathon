## ⚠️ Prototype Access Instructions

This prototype is developed using **Google Apps Script with Google Sheets as the backend database**.

Because the prototype uses Google services to process scheme data and user inputs, Google may display an **authorization/permission screen** when the web application is opened.

### To access the prototype:

1. Open the **Live Prototype** link.
2. Sign in with a Google account if prompted.
3. If Google displays an authorization screen, select **Review permissions**.
4. Select the Google account you want to use for the demonstration.
5. Click **Allow** to grant the permissions required by the prototype.
6. After authorization, reopen the prototype link if required.

### Important

* The authorization is required because this is an **SIH prototype built on Google Apps Script and Google Sheets**.
* The prototype does **not require access to the evaluator's personal Google Drive files or Gmail** beyond the permissions shown by Google.
* The application uses Google Sheets as the backend datastore for the prototype.
* No personal information should be entered into the prototype during evaluation unless explicitly required for demonstration.

### Demo Recommendation

For the smoothest demonstration, use the provided **Demo Profile** inside the application.

> **Note:** The prototype is an MVP demonstration and is not intended to represent the final production deployment architecture. A production version would use a dedicated backend/database and would not require evaluators to authorize access to the development spreadsheet.
